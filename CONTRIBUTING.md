# Contributing

All changes land via a pull request — including Richard's own changes and changes made by an AI agent on his behalf. Never push directly to `main`.

Open a PR from a feature branch, even for small changes. Hone reviews when available; if no one else has reviewed it, Hone does.

There is no branch protection configured on `main` enforcing this — it's a team convention, not a technical gate. Follow it anyway.
